# Rummikub
A mobile application that assists Rummikub players by recognizing game tiles from a camera image, validating moves according to the game rules, and suggesting possible plays using image processing and AI technologies.


# Rummikub Dataset - scrum-21

This dataset is used for training a YOLO model to recognize Rummikub tiles.

The model includes **53 classes**: numbers 1–13 in four colors and a Joker class.
Classes follow the naming convention `color_number` (e.g. `red_7`, `blue_12`, `joker`).

The dataset is divided into **train, validation, and test** sets, using the YOLO annotation format.
